# HglAPI 宣传页

一个 **零依赖、纯静态** 的 AI API 中转站宣传落地页。深空科技风、暗色主题、响应式布局，桌面 / 平板 / 手机均可正常展示。

## 快速预览

```bash
cd promo
node serve.mjs        # 默认 8765 端口，可改：node serve.mjs 9000
```

浏览器打开 <http://127.0.0.1:8765/> 即可。也可以直接双击 `index.html`（所有功能均可离线运行）。

## 页面结构

| 区块 | 内容 |
| --- | --- |
| Hero | 品牌口号、流式对话演示动画、核心数据（30+ 模型 / 4 厂商 / ¥5 起 / 0.03x） |
| 核心特性 | OpenAI 兼容、四厂聚合、流式秒回、低倍率、签到邀请、套餐切换 |
| 通道倍率 | 5 个分组通道卡片（0.03x ~ 0.2x） |
| 模型广场 | 四厂商热门模型 + 生图模型条 |
| 价格总览 | 25 个文本模型全量价目表，支持搜索 + 厂商筛选 |
| 快速接入 | 三步接入 + Python / Node.js / cURL 代码示例（可切换、可复制） |
| 常见问答 | 6 条 FAQ 折叠面板 |
| 底部 CTA | ¥5 开通 + QQ 群卡片（一键复制群号） |

## 合规说明

- 页面 **不出现任何真实域名**；代码示例中的接入地址以 `https://你的接入地址/v1` 占位，引导用户到控制台获取。
- 「HglAPI」为品牌名展示，不含域名；如需连品牌名也隐藏，全局替换 `HglAPI` 即可。
- 所有价格与奖励数字均来自站点公开页面（模型广场 / 登录页公告），如站点调价，请同步更新。

## 常见自定义位置

| 想改什么 | 位置 |
| --- | --- |
| 模型与价格数据 | `js/main.js` 顶部 `MODELS` 数组 |
| QQ 群号 | `js/main.js` 中 `QQ_GROUP` 常量，以及 `index.html` 中搜索 `1064762302` |
| 主题配色 | `css/style.css` 顶部 `:root` CSS 变量 |
| 文案 / 区块 | `index.html` 对应 `<section>` |
| 流式演示台词 | `js/main.js` 底部 `DEMO_SCENES` 数组 |

## 部署

整站为纯静态文件（`index.html` / `css/` / `js/`），可托管到任意静态服务（Nginx、Caddy、对象存储 + CDN、Vercel、Pages 等），无需构建步骤。
